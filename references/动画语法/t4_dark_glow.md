# t4_dark_glow · 暗场光绘

> 一句话语法：**暗底上只有发光的线和发光的粒子；一个场景只讲一个比喻（粒子＝情绪或力量，丝线＝操控，K 线＝结果）；所有图形加色叠加再做两级光晕；线从左往右画出，事件落点闪一下再扩一圈。**
>
> 第 10 种语法（第 9 种是 y6 讲解员）。片段 `scripts/engine/clips/t4_dark_glow.js` · 样例 `scripts/engine/examples/t4_dark_glow.json`（13s「谁在下单」，示意数据）· 总览 `assets/动画语法/t4_dark_glow_总览.jpg` · 配色 `assets/动画语法/t4_dark_glow_配色.jpg`。没有 `demos/` 示范片，样例 spec 就是示范：`render.py --spec engine/examples/t4_dark_glow.json`。
>
> 来源：2026-10-10 拆解一支交易心理口播片（YouTube A3zC0OAxHSY，6:25）02:00–02:12 段，只学机制；文字、数据、标签都是原创。

## ① 适用场景

- **用**：交易心理、行为金融、认知偏差、「看不见的力量在左右结果」。讲情绪、系统一/系统二、贪婪与恐惧；要夜间、电影感、严肃但不枯燥的口播。
- **用**：K 线在片子里反复出现，但它是「情绪的结果」，观众不会去核对数值。
- **别用**：观众会截图较真的数字（用 t3：有坐标轴、单位、来源）；产品发布（t2）；需要浅底或品牌色铺底的节目（加色发光只在暗底成立）。

## ② 画面构成

| 项 | 取值 | 依据 |
|---|---|---|
| 底 | 近黑 `#03040a`；中心一团径向光（配色角色 `glow`，α0.55，半径 0.55×长边）；四周暗角 α0.78；4% 胶片颗粒（压住渐变色带），每帧换一次位置（按 24fps 换在 30fps 下每 5 帧停一帧） | 原片：中心偏藏青、四角纯黑 |
| 混合 | 所有图形 `globalCompositeOperation='lighter'` 画在离屏层，重叠处越叠越亮 | 「光绘感」主要来自这一步 |
| 光晕 | 场景层 → 半分辨率 `blur(4px)`（紧光晕）→ 1/4 分辨率 `blur(6px)`（宽光晕），三层再用 lighter 叠回 | 等价于后期的 bloom；均值 36ms/帧 |
| 粒子 | 一张 64px 径向渐变贴图（白芯→颜色→透明）贴 760 次；约 4% 的亮粒子加十字星芒（α0.45，长度随机 2.5–6 倍粒径；多了、一样长都像亮片贴纸）；三色占比约 5 : 3.5 : 1.5 | 原片 |
| 光带 | 18 簇＋簇内高斯散布；两端变薄（厚度 ×(1−(2v−1)⁴×0.65)） | 均匀分布像噪点，成簇才像光 |
| 线 | 芯线 1.5px α0.85 ＋ 6px α0.12 软光；丝线上挂 23 颗珠子往下流 | 原片 |
| K 线 | 实体 α0.28 填充＋1.6px 描边，影线 1.6px；收盘价连一条 1.3px 白线 | 原片 |
| 字 | 中文宋体 `NotoSerifSC-700`（GB2312 子集）：标题 46px、标注 40px、团的标签 36px；英文小字 `CormorantGaramond-500` 20–22px（竖屏 ×1.25），全大写，字距 5–9px，取 `sub` 色 α0.9。Cormorant 的数字是旧式数字（1 像 ı），英文小字里的数字写成单词 | 原片的标题版式：宋体概念名＋拉开字距的英文 |
| 构图 | 横屏：标题 y≈0.145（字顶在 10% 安全线以下），光带 y≈0.255，K 线在 0.55–0.74，横向 0.2–0.8。竖屏：标题 0.13，光带 0.215，K 线 0.40–0.54，横向 0.1–0.9，粒子团在 (0.27, 0.36)；没给 `safe.bottom` 时下方三成不放任何东西，留给口播字幕 | 原片，两轮审片后调整 |

## 配色（可换）

加色发光对色相没有要求，**只要求底是暗的**。换配色只换色相，底的明度不动。`theme.palette` 写预设名，或写对象逐个角色覆盖：

```json
"theme": { "palette": "ice" }
"theme": { "palette": { "base": "ice", "thread": "#7fd8ff", "accent": [255, 210, 122] } }
```

| 预设 | 粒子 | 丝线 | 涨 / 跌 | 适合 |
|---|---|---|---|---|
| `ember`（默认） | 橙、粉、金 | 粉 | 青 / 粉红 | 原片配色；情绪、欲望、危险 |
| `ice` | 冰蓝、深蓝、白 | 冰蓝 | 薄荷绿 / 粉 | 理性、冷静、系统二 |
| `jade` | 翠绿、金、浅绿 | 翠绿 | 绿 / 红 | 东方、财富、长期 |
| `violet` | 品红、紫、金 | 紫 | 蓝 / 品红 | 科技、梦境、赛博 |

角色：`glow`（底的中心光）· `swarm1/swarm2/swarm3`（粒子三色）· `thread`（丝线）· `bead`（丝线上的珠子）· `up/down`（涨/跌）· `accent/hot`（两种标注色）· `ink`（标题）· `sub`（英文小字）。颜色写 `'#rrggbb'` 或 `[r,g,b]`；预设名、角色名、颜色格式写错都在启动时报错。

涨跌色：预设沿用原片的「青涨、粉红跌」（国际惯例）。面向 A 股观众写 `data.upDown: "cn"`，两色互换成红涨。一支片里同一个颜色只讲一件事：粉红既是「跌」又是「情绪」时，口播要讲的正是「情绪带来下跌」，不然换一套配色。

## ③ 运动轨迹

- **粒子团**：每颗粒子绕团心转（±0.25–0.75 rad/s），半径 ±6% 呼吸；按出发顺序 0.8s 淡入。
- **扫成光带**：粒子出发延迟 d = 目的地横向位置×0.55＋随机×0.35，1.0s 内沿二次曲线飞到光带（`MO.smooth`）。控制点取起点到终点横向 70%、纵向 15% 处，也就是先往右、再往上，飞行时画 0.1s 拖尾（α0.3，线宽 0.25×粒径；再亮核心就糊成一块白），整团拖成一束彗尾。
- **光带**：每颗粒子按两个频率的正弦在原位漂移（±7 / ±5px），亮度在 0.55–1 之间闪。
- **K 线**：按根数从左往右画（默认 2.6s，`MO.smooth` 缓入缓出），每根在 1.6 根的宽度里长出：实体从开盘价长到收盘价（`expoOut`），影线同步展开。线头一个白点加星芒，画完后 0.4s 淡掉。
- **丝线**：依次垂下（间隔 0.42s，每根 0.75s，`MO.smooth`）；顶端比底端更靠画面中心（×0.88），中段外鼓 14px；线头一个白点。落点在 0.62s 起闪（这时线头离落点只剩约 4%，被线头的光点盖住，看上去已经碰到；等到 0.7s 再闪会晚约 0.1s），0.12s 长到全尺寸再从 76px 回落到 46px，加一圈 0.9s 波纹；挂点附近的光带粒子变亮。
- **染色（可选）**：thread 写 `data.tint: true` 时，最后一根丝线落定后 1.4s，两端之间的上涨 K 线从 `up` 色渐变成 `down` 色，表示被情绪接管。默认不染：染完涨跌就分不出了，只在口播明说「全被情绪接管」时开。
- **标注**：光点 0.5s 弹出（`expoOut`），之后半径 ±12% 脉动，每 1.4s 扩一圈波纹（最大 50px）；文字晚 0.15s、用 0.4s 淡入。文字位置依次试正下方、右侧、左侧、左上、右上，取第一个不压 K 线和丝线、不压已放的标注、不进字幕区的位置。都不行时（竖屏窄，常见）退到正下方更低处，让开下面的 K 线和已放的标注，并画一条细引线连回落点。
- **标题**：0.9s 从 `blur(10px)`、下沉 12px 浮出。
- **相机**：整段匀速慢推 1→1.035，中心略偏上，不晃。`out`：1s 整体暗下去。

## ④ 转场（原片里观察到的；片段本身不做转场，由管线剪接）

1. **暗场硬切**：上一镜退到全黑再切，原片最常用。片段的 `out` 就是前半段。
2. **粒子重组**：上一镜的粒子团就是下一镜的原料（系统一的团 → 情绪脑的光带）。片段里 `swarm → band` 演示了这一招。
3. **坍缩成一条线**：满屏 K 线收成一条平滑发光线，接「拉长周期」。片段没做。
4. **实拍空镜**：城市夜景、眼睛特写放在章节之间，给观众喘口气。素材自备。

## ⑤ 节奏与文字

- **镜头时长**：一个比喻场景 8–15s，内部按口播分 3–5 个动作（团 → 光带 → K 线 → 丝线 → 标注），每个动作 1–3s。竖屏画面只有横屏一半宽，series 建议不超过 30 根，否则 K 线在手机上缩成一条细线。
- **与口播对位**：标题对概念名第一次出现；丝线落点对「被……控制」一类动词；标注对具体动作名（抄底、追高、开仓）。
- **文字少**：标题是不超过 5 个字的概念名＋英文小字，标注是两字动作＋英文小字。原片底部有烧录字幕，画面里几乎不放句子；做口播片时给 `spec.safe.bottom` 留出字幕带。
- **示意数据**：不给 `series` 时按种子生成一段「先涨、阴跌、V 底、再涨」，并标「示意数据」（横屏右下，竖屏右上：竖屏右下角常被平台按钮压住）；给了真实 `series` 就不标。

## ⑥ 代码实现要点

- 片段一个文件，自带种子随机、粒子贴图和光晕，没加新的 lib。参数化片段的 `clip.html` 不加载 `lib/post.js`，所以光晕写在片段里；以后多个语法要用，再把这两级光晕挪进 `post.js`。
- 所有运动都是 t 的纯函数，随机全部来自 `data.seed`（默认 20261010）。
- 所有校验都放在 `init`：错的预设名、角色名、颜色格式，越界的 `thread` / `mark` index，缺 o/h/l/c 的 candle 数据，都在启动时报错，不会渲到一半才失败。
- 字体：Google Fonts 的 `NotoSerifSC[wght].ttf` 用 fontTools instancer 实例化 `wght=700`，再 `font_subset.py --gb2312` 抽子集（6927 字，1.8MB）。
- `--alpha`：不画底和颗粒，光晕照样加色叠在透明层上。
- cue 一览见 `09-视频动画语法.md` 的「t4_dark_glow」小节。

## ⑧ 最容易做错的 3 件事

1. **粒子起点夹在终点中间。** 团放在光带中段下方时，粒子往两边四散，像爆炸。起点要在所有终点的同一侧（团在光带左端的左下方），才拖得成一束。
2. **光带分布太匀。** 均匀撒点像噪点，要成簇，两端变薄。
3. **底太亮。** 加色叠加在浅底上会洗白，光晕看不见。换配色只换色相，底一律近黑。

## 审片修订（2026-10-10，独立 agent 只看成片，6.5/10）

| 问题 | 改法 |
|---|---|
| 收尾标注字太小（中文约 25px、英文约 10px），还被波纹穿过、压着后面的 K 线 | 中文 40px、英文 17px；文字放落点正下方并让开 K 线；波纹最大 50px |
| K 线起笔和粒子横扫在同一时刻，起笔被横扫盖住 | 样例里 K 线晚 1.4s 开画（band 2.0 → candle 3.4）；做片时也别让两件事同时发生 |
| 团的标签太小、只停约 1s，和后面的标题名字对不上 | 标签 36px，停 1.5s；样例里团就叫「情绪脑」，标题改成「谁在下单」 |
| 染色后整段同一个颜色，涨跌分不出 | 染色改成可选（`data.tint`），默认关 |
| 横扫核心是一整块纯白 | 拖尾 α0.55→0.3、线宽 0.35→0.25 |
| 标题顶边离画面上边只有 5% | 版式整体下移，标题字顶在 10% 以下 |
| 落点闪光晚两帧，一帧跳满 | 0.7s 起闪，0.12s 长满 |
| K 线画笔匀速、到头急停；星芒太多像贴纸；背景渐变有色带 | 画笔改 `MO.smooth`；亮粒子 7%→4%；颗粒 3%→4% |
| （没改）「片子里用了两种中文字体」 | 误判：标题、标签、标注都是同一款 NotoSerifSC-700，小字号加光晕时看起来像黑体 |
